## ⚡ 1-Click Quick Scaffolding (`degit`)

Clone any self-contained starter template directly into a new directory:

```bash
# 1. 3-Stage Animated Password Recovery & Auth Wizard
npx degit belal-waheed/app-blueprints/templates/auth-recovery-wizard my-auth-app

# 2. Offline-First PWA with Multi-Device LWW Sync & Android 12 Share Target
npx degit belal-waheed/app-blueprints/templates/pwa-offline-sync my-sync-app

# 3. Universal Media & Link Metadata Scraper API
npx degit belal-waheed/app-blueprints/templates/universal-media-scraper my-scraper-api

# 4. Headless Microsoft Edge Playwright Test Suite
npx degit belal-waheed/app-blueprints/templates/edge-browser-automation my-edge-tests
```

## 🤖 AI / LLM Agent First Architecture

This repository is structured so that **human developers and AI coding agents** (Antigravity, Cursor, Claude, ChatGPT, Copilot) can immediately discover and apply battle-tested architectures.

| File | Target Audience | Description |
| :--- | :--- | :--- |
| [`llms.txt`](llms.txt) | AI Models & Assistants | Standardized LLM index & sitemap of all patterns |
| [`llms-full.txt`](llms-full.txt) | Context Windows | Unrolled complete context for 1-shot prompt injection |
| [`AGENTS.md`](AGENTS.md) | Autonomous Agents | Operating runbook, architectural rules, and prompt recipes |
| [`PATTERN_TEMPLATE.md`](PATTERN_TEMPLATE.md) | Contributors & You | Standardized schema for adding new patterns as you learn |
